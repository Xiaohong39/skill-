# 广告宣传片格式指南（15s–3min）

适用：品牌形象片、产品功能片、剧情广告、信息流 / 短视频带货、公益宣传片。

## 核心特征

- **单一卖点**：一支广告只说一个核心信息，其他全部删掉。
- **黄金 3 秒**：前 3 秒必须让观众停下；用视觉奇观、痛点、反常识或直接利益点。
- **情绪驱动**：广告卖的是感受和结果，不是参数；参数只作为可信度支撑。
- **明确 CTA**：结尾有清晰行动提示（购买 / 关注 / 记住品牌 / 改变认知）。

## 结构模板

### 15 秒单卖点型

1. 钩子（0–3s）：一个强画面或反常识问题。
2. 痛点 / 冲突（3–8s）：把问题放到最具体的生活瞬间。
3. 解决与利益点（8–13s）：产品出现，展示改变后的结果。
4. CTA（13–15s）：一句短促行动指令 + 品牌收束。

### 30 秒剧情型

1. 钩子（0–5s）：人物进入一个日常但异常的场景。
2. 冲突升级（5–15s）：没有产品时的麻烦被放大，但不过度夸张到失真。
3. 转折（15–22s）：产品介入，结果改变，重点拍“改变后的状态”而非讲解。
4. 情感落点（22–27s）：一个可记忆的画面或动作收束情绪。
5. CTA（27–30s）：品牌 + 一句话利益点。

### 60 秒–3 分钟品牌故事型

可加入完整微型叙事：人物目标 → 阻碍 → 转折 → 价值升华 → 品牌关联。但每个段落仍要服从单一卖点。

## 人物与场景缩放

- 人物：功能性形象，突出一个可记忆特征（职业 / 年龄 / 状态）。
- 场景：极简、符号化，画面信息集中在与卖点相关的部分。
- 对白：尽量少，用画面和动作完成信息传递；台词短促、口语化。

## CTA 与承诺边界

- 允许的 CTA：行动指令型，如“上抖音搜山岚”“点击下方链接领取”“去门店试色”“关注，下集继续”。
- 允许的利益点：具体、可被画面展示的结果，如“第二天肤色看起来更透亮”“妆前不卡粉”。
- 禁止的承诺型文案：绝对化与医疗化效果承诺，如“一夜回春”“根治敏感”“七天白三个度”“人人有效”。
- 若利益点与合规边界冲突，优先写“结果状态”，不写“保证效果”，把行动交给 CTA。

## 广告自检清单

- [ ] 全片是否只传递一个核心卖点？
- [ ] 前 3 秒是否足够抓人？
- [ ] 产品介入前，观众是否清楚“没有它会发生什么”？
- [ ] 产品介入后的结果是否用画面展示，而不是靠角色说出来？
- [ ] 是否有清晰 CTA？
- [ ] 品牌出现是否有记忆点，而非硬贴 logo？
- [ ] 台词是否像真人说话，无广告腔、无夸张承诺？
- [ ] 时长是否符合 15s / 30s / 60s / 3min 的节奏要求？
