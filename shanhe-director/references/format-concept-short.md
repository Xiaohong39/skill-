# 概念 / 创意短片格式指南（1–3min）

适用：What-If 型、How-to-Tell 型、高概念创意短片、形式实验短片。核心武器是概念的锐度和视听语言的冲击力，而不是完整人物弧光。

## 两条创作路径

- **What-If 型**：假设一个反常识前提，展示它的后果和推演。核心是概念的纯度和组合。
- **How-to-Tell 型**：用一种出人意料的叙事形式，重新讲述一个已知的事。核心是形式本身的创意。

进入创作前先确认用户要做哪条路径。

## What-If 概念组合方法

1. **概念嫁接**：把概念 A 的运行机制，放进概念 B 的场景。例：淘汰机制 + AI 焦虑 = “AI 给员工打分，低分者工位自动清空”。
2. **时空错置**：把人物 / 技术 / 制度放到不属于它的时代或地点。例：外卖骑手 + 古代驿站。
3. **隐喻具象化**：把抽象社会焦虑变成一个可被拍到的物理规则。例：容貌焦虑 → “额头会显示别人能看到的评分”。
4. **反转并置**：把两个表面相似、本质对立的事物放在一起互相照出荒诞。例：精致养宠 + 肉类工业化。
5. **规则反转**：把一个习以为常的规则取反，再推演后果。例：年龄越大越成熟 → “人生来是老人，越活越年轻”。

组合检验：
- 是否产生 1+1>2 的化学反应？
- 观众能否在 5 秒内理解规则？
- 是否指向真实社会情绪或人性弱点？
- 规则推到极限时是否有推演空间？
- 结尾是否能反过来给观众一击？

## What-If 结构

- **经典三段式**：概念呈现（15–30s）→ 推演（30–90s，2–5 个递进切片）→ 翻转（15–30s）。
- **递进崩塌式**：规则建立 → 第一次升级 → 第二次升级 → 崩溃点 → 余像。
- **双线并置式**：两条线平行推进，某个瞬间观众发现它们是一件事的两面。
- **循环式**：结尾回到开头，但观众的理解已改变。
- **倒叙揭示式**：先给结果或异常画面，再逐步揭开原因。

## How-to-Tell 创意方法

1. **视角置换**：换一个不寻常的视角讲熟事。
2. **形式模拟**：用伪纪录片、屏幕录制、数据可视化、说明书等形式包装。
3. **时间手术**：倒放、循环、跳切、定格等时间处理。
4. **尺度跳跃**：把熟悉事物放到微观或宏观尺度。
5. **规则限制**：给全片设定一个极端的视听或语言限制。

How-to-Tell 的结构：形式建立 → 规则递进 → 形式被打破或完成翻转。形式必须不可替代，去掉形式后故事不成立。

## 视听语言武器库

- **镜头**：一镜到底、固定机位时间流逝、连续推轨、第一人称 POV、微距 / 显微。
- **剪辑 / 时间**：跳切蒙太奇、分屏、交叉剪辑、倒放、定格 / 时间冻结。
- **画面构成**：对称构图、前景 / 背景双叙事、色彩限制。
- **声音**：画面与声音错位、环境音放大、关键时刻静默。
- **界面 / 媒介**：屏幕录制、伪纪录片、数据可视化。

选择原则：
- 形式服务内容，先有概念再选手法。
- 一部片子聚焦 1–2 种核心手法，用到极致。
- 手法要有递进，可在结尾被打破或反转。

## 概念 / 创意短片陷阱

- 概念需要大量解释才能懂 → 换概念或降级为叙事短片。
- 推演只是重复概念，没有递进 → 每个切片必须更极端 / 更荒诞 / 更日常。
- 翻转是硬转，与前面无逻辑关系。
- 试图塞入完整人物弧光 → 聚焦概念。
- 用台词解释概念 → 改成画面展示。
- 视听手法与概念无关，或一部片塞太多手法。
