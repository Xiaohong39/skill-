# 分镜脚本规范与连续性自检

分镜脚本把剧本变成一个个可拍摄、可生成、可执行的镜头。核心要求：自然流畅、运镜有动机、画面描述不矛盾。

## 分镜表结构

每个镜头一行，列如下：

| 镜号 | 场景 | 景别 | 运镜 | 时长 | 画面描述 | 台词 / 声音 | 转场 | 情绪节奏 | 关联资产ID |
|------|------|------|------|------|----------|-------------|------|----------|------------|

- **镜号**：SHOT-01、SHOT-02…… 顺序编号。
- **场景**：对应剧本场景编号与地点 / 时间。
- **景别**：见下方景别表。
- **运镜**：写完整动作，例如“从中景缓慢推至特写”，而不是只写“推”。
- **时长**：预估秒数，与剧本时长预算一致。
- **画面描述**：只写画面内能看到的元素，不写心理、不写“感觉”；画面元素之间不能互相矛盾。
- **台词 / 声音**：对白、旁白、环境声、音乐情绪。
- **转场**：切 / 叠化 / 甩镜 / 匹配剪辑 / 声音先入等。
- **情绪节奏**：情节紧 / 松 × 情感重 / 轻。
- **关联资产ID**：该镜头出现的资产 ID，使用 `references/asset-integration.md` 的正式前缀（SCENE-01 / PROP-01 / CHAR-01 / COST-01 / FX-01）。若资产表尚未生成，按这些前缀临时分配，后续资产整合步骤必须沿用并锁定，不得重新编号。

## 景别

- 大远景 / 远景：交代环境与空间关系。
- 全景：人物全身与环境关系。
- 中景：人物膝盖以上，兼顾动作与关系。
- 近景：人物胸部以上，突出表情与情绪。
- 特写 / 大特写：局部细节，强调信息或情绪重音。

## 运镜设计

运镜必须写清楚「起幅 — 运动 — 落幅」：

- **固定**：机位不动，靠画面内运动或时间流动。
- **推 / 拉**：推近强调，拉远揭示环境或抽离情绪。
- **摇**：水平或垂直扫视，建立空间关系或发现信息。
- **移 / 跟**：跟随主体移动，制造沉浸与空间揭示。
- **升降**：改变视点高度，常用于开场建立或情绪升华。
- **环绕**：围绕主体，制造张力或展示全貌。
- **手持**：增加真实感、不安感。
- **甩镜 / 抽帧 / 慢门 / 升格**：用于转场或情绪强化，不能滥用。

运镜动机规则：
- 每次运动都要回答“为什么动”：为了揭示、强调、跟随、制造不安，还是情绪转折。
- 一部短片聚焦 1–2 种核心运镜语言，可递进或结尾打破。
- 景别变化要有逻辑：从建立空间到进入情绪，不能来回无目的地跳。

## 画面连续性自检（防止矛盾）

- **空间一致**：同一场景的门窗、家具、道具位置前后一致；轴线不越轴。
- **时间一致**：白天 / 黑夜、天气、光线方向前后一致，除非剧情要求变化。
- **人物一致**：服装、发型、配饰、妆造在同场连续镜头中一致。
- **道具一致**：角色手中的物品、桌上的东西不能凭空出现或消失。
- **动作连续**：上一个镜头的动作终点与下一个镜头起点能接上；匹配剪辑时给出明确的动作衔接点。
- **光影一致**：主光方向、色温、阴影方向在同场景内保持稳定。
- **景别与空间关系一致**：特写中的背景元素应与前后全景中的位置一致。

## 分镜自检清单

- [ ] 每个镜头是否都能被拍出来 / 被生成出来？
- [ ] 运镜是否写清起幅—运动—落幅，且有叙事动机？
- [ ] 画面描述是否只写可见元素，无心理、无情绪名词堆砌？
- [ ] 相邻镜头之间是否存在空间、时间、服装、道具、光影矛盾？
- [ ] 景别序列是否形成“建立 → 进入 → 强调 → 释放”的逻辑？
- [ ] 每个镜头都有时长，总时长符合体量要求？
- [ ] 台词 / 声音是否与画面同步，无“角色说 A 画面演 B”的错位？
- [ ] 转场是否自然，是否出现无理由的炫技转场？
