# 类型化框架与风格标签库

在进入剧本前，根据用户需求确定类型和风格标签；这些标签会写进「影片整体风格卡」，并被所有提示词继承。

## 类型化框架

| 类型 | 核心张力 | 运镜 / 节奏倾向 | 光影与色彩倾向 |
|------|----------|----------------|----------------|
| 广告宣传 | 痛点 → 结果 | 快节奏、强钩子、利落转场 | 高饱和、产品高光、干净背景 |
| 科幻 | 规则对人性 / 关系的放大 | 慢推、大远景、冷峻或未来感 | 冷色、高对比、霓虹 / 金属质感 |
| 文艺 | 内在情感与日常质感 | 固定长镜头、手持微晃、留白 | 自然光、低饱和、胶片颗粒 |
| 悬疑 | 信息差与未知 | 缓慢推进、特写堆叠、突然静止 | 阴影重、冷暖对撞、压抑色调 |
| 爱情 | 靠近与错过 | 柔和移动、特写与近景为主 | 暖调、柔光、浅景深 |
| 喜剧 | 预期错位 | 节奏快、动作夸张、跳切 | 明亮、高饱和、平面感或生活化 |
| 自媒体 | 注意力与代入感 | 竖屏、快切、第一视角、字幕友好 | 明快、对比强、口播突出 |

类型可混合，但要明确主类型：主类型决定节奏和光影基线，副类型只做局部调味。

## 风格标签库

在风格卡中给出 3–8 个风格关键词（中英双语），例如：

- 导演质感：韦斯·安德森式对称、诺兰式冷峻、宫崎骏式治愈、王家卫式霓虹 / 抽帧、侯孝贤式长镜头。
- 视觉质感：赛博朋克、国潮新中式、极简北欧、复古胶片、Y2K、水墨、黏土定格、2.5D、电影级写实。
- 镜头质感：浅景深、变形宽银幕、手持纪实、一镜到底、微距、鱼眼。
- 色彩 / 光影：莫兰迪低饱和、青橙、金暖、冷蓝、单色 + 强调色、自然光、霓虹夜色。
- 声音 / 节奏：抽帧、慢门、快切、升格、留白、ASMR。

## 使用规则

- 风格标签必须服务于内容，不为了“看起来高级”而堆叠。
- 一旦写入风格卡，后续所有资产和提示词必须沿用，不得随意更换。
- 若用户指定导演 / 作品风格，优先把该风格拆解为可执行的色彩、光影、运镜、材质关键词，而不是只写一个名字。
