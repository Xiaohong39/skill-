# 美术资产整合规范

把剧本和分镜中的视觉元素整理成可复用的 AI 美术资产清单，避免同一个角色 / 道具在不同镜头中“长得不一样”。

## 资产表结构

| 资产ID | 类型 | 名称 | 描述 | 出现镜号 | 风格继承 | 复用 / 变体 |
|--------|------|------|------|----------|----------|-------------|

- **资产ID**：唯一编号，规则见下方。
- **类型**：场景 / 道具 / 角色 / 服饰 / 特效 / 其他。
- **名称**：稳定称呼，全片统一。
- **描述**：外形、材质、颜色、年代、关键识别特征；只写可见信息。
- **出现镜号**：该资产出现或影响到的所有镜号。
- **风格继承**：引用风格卡中的关键词，确保一致。
- **复用 / 变体**：标注“同一资产复用”或“某资产的时间 / 状态变体”，说明变化规则。

## 资产 ID 规则

- 场景：`SCENE-01`、`SCENE-02`
- 道具：`PROP-01`、`PROP-02`
- 角色：`CHAR-01`、`CHAR-02`
- 服饰：`COST-01`、`COST-02`
- 特效：`FX-01`、`FX-02`
- 其他：`ASSET-01`

编号按首次出现顺序递增；同一资产全片只用一个 ID，状态变化用“复用 / 变体”说明。示例：白瓷精华瓶全片固定为 PROP-01，夜间与晨间只是同一资产的不同光影状态，不另设编号；分镜阶段若已临时使用 PROP-01，本步骤必须沿用锁定，不重新编号。

## 资产分类与描述要求

- **场景**：地点、时代、空间尺度、核心陈设、氛围光、可进入的机位关系。
- **道具**：尺寸、材质、颜色、新旧程度、与角色的交互方式；对关键道具写清识别特征。
- **角色**：年龄、体型、发型、肤色、面部特征、标志性姿态；不写心理。
- **服饰**：款式、颜色、材质、配饰、穿着状态；同角色不同场次需说明是否换装。
- **特效**：光效 / 粒子 / 天气 / 屏幕 UI / 变形等，写清触发条件与视觉表现。

## 关键帧清单

从分镜中挑出决定全片视觉走向的关键画面，输出：

| 关键帧ID | 镜号 | 画面说明 | 关联资产ID |
|----------|------|----------|------------|

- 每个关键帧对应一个镜头或一个视觉转折点。
- 后续图片提示词必须覆盖所有关键帧，并为每个美术资产各生成一条单独提示词。

## 资产整合自检清单

- [ ] 每个场景 / 道具 / 角色 / 服饰是否都有唯一资产 ID？
- [ ] 同一角色、同一场景在不同镜头中的描述是否一致？
- [ ] 所有资产是否都写进了出现镜号？
- [ ] 复用 / 变体关系是否明确，避免同物不同名？
- [ ] 资产描述是否只写可见信息，没有心理或叙事功能描述？
- [ ] 关键帧是否覆盖开头钩子、转折、高潮、结尾等关键节点？
