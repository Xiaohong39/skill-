# 风格卡与中文提示词规范

所有提示词先有统一风格，再落到每个资产、关键帧和镜头。

## 一、影片整体风格卡

在产出任何提示词前，先输出风格卡。它是唯一风格来源：

```text
【山河导演意见】
（3–6 条本模块导演判断）

【影片整体风格卡】
- 影片名 / 类型 / 体量 / 平台 / 受众：
- 核心风格定位：
- 视觉基调（色彩 / 光影 / 镜头质感 / 构图 / 景别倾向）：
- 场景基调（时代 / 地域 / 空间质感）：
- 道具基调（材质 / 年代 / 色彩）：
- 角色与服饰基调（形象 / 服装 / 妆造）：
- 视频基调（运镜 / 节奏 / 转场 / 声音）：
- 风格关键词（中英双语）：
```

风格关键词之后将作为所有提示词的统一前缀，例如：

`国潮新中式 / 朱砂红与黛蓝 / 柔光电影质感 / 对称构图 / 慢推镜头`

## 二、图片提示词（gpt-image-2 / image2）

为每个美术资产和每个关键帧各写一条中文提示词。结构固定：

```text
[风格前缀] + [主体/场景] + [关键细节：材质/光影/构图/镜头] + [约束] + [输出意图]
```

示例（关键帧）：

```text
国潮新中式，朱砂红与黛蓝，柔光电影质感。一家老字号护肤铺的中景，青石柜台摆着白瓷瓶，瓶身有细金纹；晨光从雕花木窗斜入，空气中浮着细微尘粒。对称构图，中景，浅景深。角色与道具保持同一时代质感，不出现现代品牌字。电影级关键帧，高细节。
```

规则：
- 中文为主；品牌名、英文风格词可保留原文。
- 只写可被图像模型理解并稳定生成的可见信息，不写叙事意图。
- 每个资产提示词强调其唯一识别特征，便于后续生成一致。
- 关键帧提示词必须引用对应资产的识别特征，避免同物不同貌。
- 约束里写明“不出现”的禁止项，防止模型自由发挥。
- 不调用生成工具，只输出提示词。

## 三、视频提示词（通用）

为每个分镜写一条中文视频提示词。结构固定：

```text
[风格前缀] + [画面内容] + [运动/运镜] + [节奏与时长] + [声音/情绪] + [转场衔接]
```

示例：

```text
国潮新中式，朱砂红与黛蓝，柔光电影质感。少女推开雕花木门，白瓷瓶在晨光中反光；镜头从门口缓慢推近到她的侧脸，再随她视线下摇到瓶身。约 4 秒，舒缓，环境声是木门轻响与远处市声。结尾叠化到下一镜的瓶身特写。
```

通用适配说明（可附在整批视频提示词末尾）：

- 可灵 / Vidu / 即梦等平台通常接受“主体 + 运动 + 镜头运动 + 氛围 + 时长”结构；发送时保留统一风格前缀。
- 平台不支持复杂转场时，把“叠化 / 甩镜”改为“硬切”或去掉，改由剪辑完成。
- 竖屏平台优先给出 9:16 构图提示；横屏电影感短片优先给出 16:9 或 2.39:1 构图提示。

## 四、一致性规则

- 同一资产、同一角色在全部提示词中使用相同名称、相同识别特征和相同风格前缀。
- 场景、光影、服装、道具的描写不得与分镜和资产表矛盾。
- 同一镜头下的关键帧提示词与视频提示词必须指向同一画面内容。

## 五、提示词自检清单

- [ ] 每条提示词都带统一风格前缀？
- [ ] 只写可见、可生成、可拍摄的内容？
- [ ] 资产 / 关键帧 / 镜头的识别特征前后一致？
- [ ] 图片提示词包含主体 / 细节 / 构图 / 约束 / 输出意图？
- [ ] 视频提示词包含画面 / 运动 / 节奏 / 声音 / 转场？
- [ ] 未出现与分镜或资产表矛盾的描写？
- [ ] 是否误写了“生成动作”而不是提示词内容？（本技能只输出提示词）
