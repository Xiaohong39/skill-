# 叙事短片格式指南（3–10min）

适用：故事片、自媒体内容、文艺短片、科幻短片、悬疑 / 爱情 / 喜剧等有完整起承转合的短片。

## 核心特征

- 有完整人物弧光：从状态 A 到状态 B 的不可逆变化。
- 有清晰的戏剧动作：角色想要什么、被什么挡住、最终得到 / 失去什么。
- 节奏有张弛：高潮前有铺垫，高潮后有呼吸。
- 开场即钩子：第一场戏直接进入冲突或异常。

## 四段式结构

1. **建立（约 15%–20%）**：用最短时间让观众认识角色、处境和“异常”。不从头讲背景，通过行为反推。
2. **发展（约 50%–60%）**：冲突逐步升级，每个场景推动角色离原状态更远；可设置一次假转机或伪解决。
3. **高潮 / 转折（约 15%–20%）**：角色面对最大阻碍，做出不可逆选择。
4. **结局（约 10%–15%）**：结果落地，留一个可回味的画面；可开放，但情绪要完整。

示例（8 分钟）：建立 1.5min / 发展 4min / 高潮 1.5min / 结局 1min。可调整，但要知道为什么调。

## 自媒体节奏附加要求

- **黄金 3 秒**：第一镜必须给到视觉钩子或异常。
- **每 20–30 秒一个反转或新信息**：防止划走。
- **结尾留钩子**：让观众看到最后一秒、想评论或关注。
- **对白短促**：单句短，信息密度高，适合竖屏阅读节奏。

## 文艺片处理

- 情节可慢，但情绪必须持续递进；用动作、停顿和环境承载情绪。
- 避免用旁白解释主题；让画面和细节说话。
- 节奏错位常用：情节松 + 情感重。

## 科幻片处理

- 世界规则必须 5 秒内可懂，不在台词里长篇解释。
- 概念要落到具体动作或视觉符号上，不空谈设定。
- 人物关系仍是核心，科幻规则是放大镜，不是主角。

## 叙事短片陷阱

- 前史交代过长，故事迟迟不开始。
- 高潮太短或结局拖沓。
- 角色想要的东西不够具体，阻碍不构成对抗。
- 连续长时间单一情绪，没有呼吸段。
- 台词解释设定或主题。
- 开场没有钩子，观众 3 秒内不知道看什么。

## 叙事短片自检清单

- [ ] 开场 3 秒有钩子？
- [ ] 主角有明确的 Want，阻碍与 Want 直接对抗？
- [ ] 每场戏都有目标 + 阻碍 + 结果？
- [ ] 高潮是角色主动做出的不可逆选择，而非偶然事件？
- [ ] 时长分配符合四段式？
- [ ] 节奏有张弛，高潮前后有呼吸？
- [ ] 台词口语化，无心理描写、说教、解释性台词？
- [ ] 删掉台词后，动作仍能大致看懂故事？
