# 通用编剧方法论（15s–10min 短片 / 广告 / 创意片）

本文件是编剧能力的底层方法论，所有格式共用。目标是让每一个场景都能被摄影机拍出来，让每一句台词都像真人在说话。

## 一、核心原则：故事从中间开始

不要从“很久以前”讲起。影片是生活的一个横截面：世界在故事开始前已经运行，角色带着前史走进第一场戏。

- 先知道前史、世界、关系，再选择从最有张力的瞬间切入。
- 开场即态度：第一场戏定义全片气质，必须精心设计。
- 观众不需要立刻理解所有背景，他们通过角色的动作和反应反推。

## 二、戏剧动作：故事的最小单位

**戏剧动作 = 目标 + 阻碍。** 每个场景至少有一个微型戏剧动作：角色想要什么、被什么挡住、结果如何（成功 / 失败 / 意外转向）。微型戏剧动作向上汇聚成全片核心戏剧动作。

自检：
- 目标是否有紧迫性？
- 阻碍是否与目标直接对抗？
- 这场戏去掉后，故事是否仍成立？（如果不成立，说明它承担了叙事功能）

## 三、人物设计

- **Want（外在需求）**：角色自己知道并主动追求的目标。
- **Need（内在欲望）**：角色未必意识到的深层缺口，是 Want 的根源。
- **弧光**：从状态 A 到状态 B 的不可逆变化；短片通常是一次性跳跃。
- **矛盾性**：角色至少有一层“外在表现 vs 内在真实”的反差。

缩放规则：

| 格式 | 人物深度 |
|------|----------|
| 广告片 | 功能性形象即可，突出一个可记忆特征 |
| 概念 / 创意短片 | 功能性 archetype，可不做完整小传 |
| 叙事短片（3–10min） | Want / Need / Arc + 一个关键矛盾特征 |

## 四、视听化写作

- **Show, Don't Tell**：不写“他害怕了”，写“他把手机攥紧，指节发白”。
- **动作即潜台词**：删掉所有台词后，观众仍能大致看懂发生了什么。
- **台词像冰山**：只露一角；用停顿、回避、话题转移表达真意。
- **口语化**：不同角色用词、句式长度、口头禅不同；不写书面化的 AI 腔。

红线（绝不出现）：
- 心理描写：他意识到 / 她领会到 / 内心涌起
- 括号暗示：（其实是在掩饰紧张）
- 角色解释设定或主题的台词
- 说教、强行催泪、煽情独白
- 无法被摄影机拍到的内容

## 五、标准剧本格式

```text
【场景1：天台 / 夜 / 城市霓虹在雨雾里晕开】

角色A没有回答。他走到栏杆边，把打火机按了三下，火苗始终没亮。

角色A：你带伞了吗？
角色B：没带。反正也快到了。

角色A把打火机收回口袋，抬头看了一眼对面楼顶的广告牌。
```

规则：
- `【场景标注】` 用方括号，写地点 / 时间 / 关键视觉。
- `角色名：` 直接跟对白。
- 旁白或内心独白用 `角色名（OS）：`，但少用。
- 动作 / 画面描写不加标记，直接写在台词之间，只写拍得到的内容。
- 每场戏标注预估时长，格式如 `（约30秒）`。

## 六、开场钩子

开场不是交代背景，而是在观众还不知道故事是什么时让他们无法移开目光。

- 可安静、可激烈，但必须产生“怎么回事？”的疑问。
- 广告片：黄金 3 秒内给到视觉奇观、痛点或反常识信息。
- 概念短片：前 15–30 秒展示规则或悬念，不解释。
- 叙事短片：第一场戏直接进入冲突或异常，不从头铺垫。

## 七、双轨节奏与时长估算

节奏有两条轨道：
- **外部情节节奏**：事件密度与强度（紧 / 松）。
- **内在情感节奏**：角色情感波动（重 / 轻）。
- 两轨可以错位，错位本身是高级手法；避免长时间同时高位或同时低位。

时长估算：
- 中文约 200–250 字对白 + 动作 ≈ 1 分钟成片。
- 纯对话场景按字数估算；动作 / 蒙太奇按画面数估算（每个独立画面 3–5 秒）。
- 沉默 / 情绪场景容易被低估，需给足 10–15 秒呼吸空间。
- 转场每次计入 2–5 秒。

## 八、编剧自检清单

每个剧本输出前检查：
- [ ] 没有心理描写、括号暗示、解释性台词、说教。
- [ ] 每场戏都有目标 + 阻碍 + 结果。
- [ ] 人物有至少一个矛盾特征（广告片除外）。
- [ ] 开场钩子是否能在 3 秒（广告）/ 15–30 秒（短片）内抓住观众。
- [ ] 台词口语化，角色之间有可辨识的说话方式。
- [ ] 每场戏有时长标注，全片时长符合目标体量。
- [ ] 删掉台词后，动作仍能大致讲清故事。
- [ ] 节奏有张弛，高潮前有足够铺垫。
